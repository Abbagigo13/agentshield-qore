FAQ

Good questions.

Does the agent ever hold a key?

No. It submits intents with an agent key that can only ask. Signing keys stay inside the gateway, and in delegated mode the owner key stays off it entirely.

What is post-quantum here?

Transactions carry a secp256k1 plus ML-DSA-87 hybrid signature, and every receipt is signed with ML-DSA-87, so the record stays provable if classical signatures later fall.

What if the gateway is hacked?

In delegated mode it holds only a delegate key that QoreChain bounds with an on-chain rule, tested on the testnet. The allowlist, rate limit, scan and approvals cannot live on-chain, and the rule does not bind the owner’s own payments.

Can the injection scan be bypassed?

Possibly. It is a pattern list, one layer among several. Limits, allowlist and human approval still apply.

Can records be deleted from the log?

Edits and mid-log deletions fail verification. Removing the last few records is only detectable if a later on-chain anchor exists.

Is this on mainnet? Is the dashboard live?

No to both. It targets the testnet, and this dashboard runs the real rules and SHA-256 chain in your browser as a demo.
